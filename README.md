# Entrepreneur School (entrepreneurschool.de)

Category: education-archives

## Concept
A free self-paced mini course for first-time founders in Germany: 8 short lessons (idea validation, customers, business model canvas, legal forms like GmbH/UG/Einzelunternehmen, pricing, first sales, financing, launch), each with a takeaway and a small exercise. Progress is saved in localStorage.

## Look
Friendly school-notebook style: paper white, ink blue and marker orange, hand-drawn-feeling headings paired with a readable body font.

## Technical Details
This is a purely static website built with vanilla HTML, CSS, and JavaScript. It does not use any frameworks, build steps, or external dependencies. It is designed to be hosted directly on GitHub Pages. Progress is tracked entirely client-side using `localStorage`.

### File Structure
- `index.html`: The main landing page and mini-course content.
- `style.css`: The stylesheet implementing the notebook theme, responsive design, dark mode, and accessibility features.
- `script.js`: The JavaScript file handling lesson toggling, progress calculation, and localStorage persistence.
- `impressum.html`: The legal notice page (with placeholders).
- `datenschutz.html`: The privacy policy page, explaining the zero-tracking nature of the site.
- `404.html`: Custom 404 error page.
- `favicon.svg`: Inline SVG favicon.
- `robots.txt` & `sitemap.xml`: Basic SEO configuration files.
- `CNAME`: Configuration for GitHub Pages custom domain.
